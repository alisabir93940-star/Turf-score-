# TurfScore - Cricket Scoring App

A comprehensive cricket team and match management application built with React.

## Features

- 🏏 Live match scoring (ball-by-ball)
- 👥 Team management with player lists
- 📊 Match history and statistics
- 🏆 Tournament management with points tables
- 🌙 Dark/Light theme support
- 💾 Local storage persistence

## Project Structure

```
├── web/                 # React web app
├── mobile/              # React Native (Expo) app
└── README.md
```

## Getting Started

### Web App
```bash
cd web
npm install
npm start
```

### Mobile App (Expo)
```bash
cd mobile
npm install
npx expo start
```

## Building APK

```bash
cd mobile
eas build --platform android
```
